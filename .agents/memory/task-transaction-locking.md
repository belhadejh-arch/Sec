---
name: Task transaction locking
description: قاعدة التعامل مع إكمال المهام والمعاملات المقفلة في PostgreSQL.
---

أي قراءة لاحقة لحالة المستخدم أثناء معاملة إكمال المهمة يجب أن تستخدم اتصال المعاملة نفسه، لا اتصال `pool` منفصلًا.

**Why:** معاملة إكمال المهمة تقفل صف المستخدم حتى الالتزام. استعلام منفصل عبر `pool` ينتظر القفل، بينما المعاملة تنتظر نتيجة الاستعلام، فيتوقف الإكمال.

**How to apply:** نفّذ تحديث الرصيد وسجل المحاولة والمعاملة داخل `withTransaction`، ثم حمّل الحمولة الكاملة من `pool` فقط بعد نجاح `COMMIT`.
