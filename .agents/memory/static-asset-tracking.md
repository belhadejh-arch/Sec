---
name: تتبّع أصول Vercel
description: نشر الصور والملفات الثابتة من مجلد الواجهة إلى GitHub وVercel.
---

قواعد Git العامة في هذه البيئة تستبعد ملفات `attached_assets` افتراضياً. قد تظهر الصورة في معاينة Express محلياً لكن لا تصل إلى GitHub أو Vercel إذا لم تكن متتبعة.

**Why:** شعار Vault ظهر محلياً، بينما أعاد مساره على Vercel استجابة 404 لأن ملف PNG كان مستبعداً من Git.

**How to apply:** لكل أصل ثابت تستخدمه الواجهة، تحقق من أنه متتبع باستخدام `git ls-files`، وأدرجه في فحص بناء الواجهة. عند الحاجة أضف الملف الفردي فقط بالقوة؛ لا تضف مجلد المرفقات كله لأنه يحتوي لقطات وملفات لا تخص النشر.
